# 02 — 交付安全可重试的 Agent API

**What to build:** 持有有效 PAT 的 Agent 可以通过版本化接口完成 TYPING 题库和分组管理，包括原子幂等导入、局部并发更新和两步永久删除。

**Blocked by:** 01 — 建立个人数据安全边界与 PAT

**Status:** completed

- [x] 题库列表支持关键词、分组、题型和有上限的分页，按创建时间倒序，并标明每个题库是否可写。
- [x] Agent 可读取所有题型详情；只有 TYPING 可创建、局部更新、导入和删除，其他写入返回稳定错误。
- [x] TYPING 创建和读取保留现有 answerList v2、parts、segments、comment 和分组结构。
- [x] 题库与分组局部更新只改变显式字段，必须携带当前版本；旧版本返回 409 和最新摘要。
- [x] 批量导入在同一事务内创建缺失分组、题库、答案、关联和复习状态；任一失败全部回滚。
- [x] 相同用户和 requestId 的相同载荷重放原结果且不重复创建；不同载荷复用 requestId 返回 409。
- [x] 分组名称按用户唯一；创建、改名和自动建组均遵守同一规则。
- [x] 题库与分组删除必须先取得五分钟有效的预览确认；过期、跨用户或版本变化均拒绝删除。
- [x] 删除预览清楚返回目标和影响；删分组只解除关联，题库仍存在。
- [x] 所有成功和失败响应使用稳定结构，原有网页导入行为保持兼容。
- [x] HTTP 集成测试覆盖鉴权、原子回滚、幂等和基本题库读写。
